# ASTHETIC BADSHAH MASALA

A portrait-mode cricket game with a futuristic hacker-style intro and custom audio experience.

## About

ASTHETIC BADSHAH MASALA is a mobile cricket game featuring a terminal-style introduction, custom branding, cricket gameplay, background music, and a special celebration effect when the batsman hits a six.

## Features

- Hacker-style black terminal intro
- Green typing animation
- Blinking terminal cursor
- Custom intro voice/audio
- ASTHETIC BADSHAH MASALA logo
- Portrait-mode cricket gameplay
- Cricket stadium and audience
- Bowler and batsman
- Cricket wicket/stumps
- Ball and bat animations
- Background music during gameplay
- Custom six celebration audio
- "SIX!" celebration animation
- Music and sound controls
- Mobile-friendly interface

## Game Flow

1. Launch the application.
2. Show the ASTHETIC BADSHAH MASALA intro.
3. Play the supplied intro audio.
4. Display the intro text with a green terminal typing animation.
5. Open the main menu.
6. Player presses START GAME.
7. Open the portrait cricket game.
8. Play background music during gameplay.
9. When the batsman hits a six, play the supplied six audio and show a celebration animation.
